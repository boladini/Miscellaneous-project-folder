## AI Workforce

A team of AI agents defined as markdown job descriptions — inspired by the
"AI with Allie" playbook. You talk to the Chief of Staff; he delegates; the
org logs its work and improves on its own.

- **`agents/`** — the roster (job descriptions):
  - `nick-fury.md` — Chief of Staff (single point of contact, delegates)
  - `directors/jarvis.md` — Operations Coordinator (**first hire**)
  - `oracle.md` — note-taker / memory & self-learning engine
  - `README.md` — org chart and conventions
- **`memory/`** — shared memory: `decisions.md`, `best-practices.md`, `sops.md`, `people.md`
- **`CLAUDE.md`** — runtime rules (draft-only, Monday as source of truth, `/loop` setup)

See `agents/README.md` to get started.
